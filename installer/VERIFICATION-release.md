# 0.5.7 发布验证

本次新增 EXE 在线安装器，完整程序仍包含本地模型与运行环境。

- 本机隔离小型分卷测试：通过 NSIS 实际下载、SHA-256 校验、静默安装与卸载；卸载保留用户数据目录和新增文件。
- 本机已有 0.5.7：TypeScript/Vite 构建与 39 项自动测试通过；最终 EXE 冷启动、重复双击单窗口、资料表和设置版本验证通过。原工作区记录与项目 ID 保持一致，CUDA 模型就绪并复用 67 条索引。
- GitHub Windows runner：使用已公开的 0.5.5 完整运行时和 SHA-256 固定的 0.5.7 发行组件组装；校验所有组件与模型文件；完整分卷与更新 ZIP 通过解压 CRC 检查。
- GitHub Windows runner：用最终 Setup.exe 和同版分卷静默安装到隔离目录，启动安装后的桌面 EXE；验证本机服务版本、直接主界面会话、首页 HTTP 响应、自动加载内置模型。实际结果记录在 `installer-verification.json`。
- 完成后退出测试客户端、只停止此安装目录的本机服务，卸载测试确认保留原资料库和新增文件。

未新增真实双机 NAS/SMB、不同系统 DPI 下的视觉验收；未模拟 GitHub 公网断包后的续传。模型 CPU 云端加载验证不代替 NVIDIA 性能验收；演示数据不作为真实项目匹配准确率证据。程序尚无商业数字签名。

更新包保留已有模型和用户工作区；首次安装使用 EXE 或全部离线分卷。EXE 是在线安装器，首次安装需下载约 4–5 GiB 完整程序文件；安装完成后搜索在本机处理，可离线使用。
