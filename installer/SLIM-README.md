本版保留 Chinese-CLIP、DINOv2、NVIDIA GPU 加速、图片／视频／音频预览及现有界面功能。移除了推理环境中不参与本软件运行的静态编译库、头文件、调试文件，以及服务端多余的前端依赖；保留运行所需 DLL、PYD、Python 源码、许可证与模型文件。

## 完整离线安装

下载本次发行附件里的 **OfflineSetup.exe 和全部 `.7z.001`、`.002` 等数据分卷**，放在同一个文件夹，保持原文件名，然后双击 EXE。安装器会直接读取旁边的数据文件，校验并自动安装；无需手动解压，不会联网补下载。EXE 只是安装入口，必须和数据文件一起使用。

首次安装不需要旧版本，也不需要另外安装 Python 或模型。安装后可离线搜索。建议为程序留出 12 GiB 空间，另留足下载文件所需空间。

使用已有资料时，先保存编辑内容并从托盘退出旧客户端，再运行新版。在设置中选择自己的工作区；工作区与程序目录独立。卸载仅删除本次安装的程序文件，保留用户资料和新增文件。

校验值见 `SHA256SUMS.txt`；精简明细见 `slim-manifest.json`；本机 GPU 检查、云端 CPU 检查和安装／卸载结果见对应验证附件。示例图测试仅证明功能可用，不代表真实项目准确率或检索 P95 达标。真实双机 NAS/SMB 与系统 DPI 视觉验收仍待实机验证。程序尚无商业数字签名。

本仓库仅公开发行文件和组装脚本，不公开项目源码归档。安装器采用 NSIS 和 7-Zip；其许可及模型许可随软件保留。
