# 快速找界面 0.5.4

灵兔风格的游戏 UI 素材资料库，支持工程名、GM、Figma 与本地截图相似搜索。

- 设置新增检查更新、下载校验、安装并重启。
- 上传处理进度与任务页可视化；文件夹独立保存 GM 和 Figma 资料。
- Windows x64 便携发行，浅色/深色主题，本机服务和模型推理运行时内置。

## 下载
新用户：下载完整包的全部分卷，放在同一目录，使用 7-Zip 从 .001 解压，然后双击“启动团队服务器.cmd”。
已有 0.5.x 用户：下载增量更新 ZIP，解压后运行“更新程序.cmd”，选择原团队便携版目录。模型和用户资料保留。0.5.4 之后可在设置内检查更新。

模型权重独立下载，可在设置中在线获取。源码不在本下载仓库公开。
