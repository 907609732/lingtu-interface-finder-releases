# 快速找界面 · 灵兔团队素材库

Windows 游戏 UI 素材管理与本地截图相似搜索工具。管理文件夹、工程名、GM、UI / 拼接 Figma、图片、视频和附件；支持本机团队服务及 NAS 共享项目。

## 下载

[下载最新正式版](https://github.com/907609732/lingtu-interface-finder-releases/releases/latest)

完整包包含运行环境及 Chinese-CLIP / DINOv2 模型，首次使用无需单独下载模型。下载完整包的全部分卷，放在同一目录，用 7-Zip 打开 `.001` 解压，然后双击“团队便携版/启动团队服务器.cmd”。

已有 0.5.x 可使用更新 ZIP；从 0.5.4 开始支持设置 → 软件更新。安装前保存编辑内容，备份程序会自动生成，用户资料及历史保留。

设置 → 项目与存储可查看、复制当前工作区路径，并打开工作区、素材和本机查询缓存。NAS 共享模型与已识别特征，本机数据库和账号独立保存。

本仓库仅公开程序发行文件、说明与组装流程，源码归档未公开。各版本限制及验证情况见对应 Release 的 VERIFICATION.md。程序未商业签名，真实双机 NAS 与系统 DPI 验收仍待进行。
