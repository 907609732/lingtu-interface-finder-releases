# 快速找界面 0.7.5 · 普通文件夹直连与紧凑资料表

状态：**0.7.5 已发布。** [下载独立 APP／扩展 ZIP](https://github.com/907609732/lingtu-interface-finder-releases/releases/tag/v0.7.5)。完成 GitHub 云端重新组装、完整性校验及双版本隔离启动测试，并下载同次产物完成本机实际运行验收。

## 更新内容

- **标题栏与紧凑布局**：标题栏随软件浅色／深色主题切换；收起文件栏后内容区铺满窗口；资料表改为单行表头，减少顶部留白。
- **本机图片回收站**：删除图片后可在回收站预览缩略图、打开图片回收站文件夹；手动替换回收副本后恢复会按新内容生成修订，不覆盖旧历史。
- **普通文件夹直连 ArtHub**：停止工作区文件夹包打包、人工提交和自动解包。资料直接保存在普通文件夹，由 ArtHub 同步该目录；SQLite、查询缓存、缩略图／预览、AI 模型和索引、显卡缓存、任务及图片回收站只留本机。
- **旧包只读迁移**：`format 3 / folder-packages` 仅作迁移来源。首次打开不创建空库；迁移先复制到旁路普通目录并校验文件哈希、修订、原件、冲突和本机回收站，失败不切换，旧目录、包、状态和回收站不删除。
- **目录状态**：设置页按真实读取结果显示本地可用、只读、缺原件／等待修订、目录缺失、权限错误和身份变化。状态查询不触发自身事件循环；本地保存成功不代表 ArtHub 云端上传完成。
- **AI 索引调度**：内容无变化时不调用 AI；仅字段等元数据变化或相同哈希的新映射不重算向量。新增、换图、删除和迟到原图保留必要增量；临时特征同步失败不提交成功指纹，下一次检查会重试；修复 Python 终态事件先于 index 响应到达的异步竞态。
- **资料表摘要**：每行每个字段默认最多显示两项，并提示剩余数量；“展开详情／收起详情”查看全部内容，保留编辑、Figma、GM、画册、排序、列宽、行高和密度功能。展开状态不写入资料。
